# David Alvarez Portfolio

Personal portfolio for David Alvarez: document management system and MENRO capstone projects.

## Adding MENRO screenshots

Put the screenshot files in `images/menro/` using these names:

- `dashboard.png`
- `dashboard2.png`
- `dashboard3.png`
- `dashboard4.png`
- `dashboard5.png`
- `waste-data.png`
- `validation-reports.png`
- `user-management.png`
- `announcements.png`

The MENRO **View project** link opens the case-study page at `projects/menro.html`.

## Adding CIAC screenshots

Put the PNG files in `images/ciac/` using these names:

- `admin-dashboard.png`
- `manage-users.png`
- `manage-departments.png`
- `admin-profile.png`
- `user-dashboard.png`
- `documents.png`
- `transaction-management.png`

The CIAC **View project** link opens the case-study page at `projects/ciac.html`.

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
